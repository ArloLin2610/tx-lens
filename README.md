# TX Lens 台指期價值區透鏡

網址：https://arlolin2610.github.io/tx-lens/

把臺股期貨（大台，TX）近月合約每一盤的成交量按價格堆起來，標出 POC、VAH、VAL 三個價格區域，並用這些區域回測一套突破多空規則。另有個股的自動錨點 AVWAP。

純靜態網站（React 19 + Vite + TypeScript），放在 GitHub Pages。資料由 GitHub Actions 在每一盤收盤後產生，**不是即時報價**。

## 頁面

- **價值區**：3 分 K 線圖疊上各盤的區域。區域來源三選一：上一盤（日盤用前一個夜盤、夜盤用當日日盤）、週累計（週一二用上週整週，週三起用本週累計到上一盤）、自選區間。最上面列出「下一盤要用的區域」和它的成交量分布。
- **多空策略**：價值區突破的進出場規則與回測，可調區域來源、價值區比例、停利倍數、成本。
- **個股 AVWAP**：日線圖上的錨定成交量加權平均價，錨點自動選（區間最高點、最低點、最大量）或自選日期。
- **說明**：算法、資料來源、限制。

## 算法

價值區（`src/lib/profile.ts`）照原始策略文件（XQ 的 XScript 指標）逐行移植，`tests/profile.test.ts` 用 300 組隨機資料核對與原程式的 POC、VAH、VAL 相同：

1. 取期間內 3 分 K 的最高、最低價，切成 `ceil(範圍 / 50) + 1` 格。
2. 每根 K 棒的成交量整根算進收盤價所在的那一格。
3. 量最大的格是 POC（同量取最低的）。
4. 從 POC 往上下擴張，每次併入量較大的鄰格（同量取上方），直到累計量達到設定比例。
5. 擴張範圍最上面一格是 VAH 區、最下面一格是 VAL 區。原文件畫三條線，本站畫整格。

盤別（`src/lib/session.ts`）：日盤 08:45–13:42、夜盤 15:00–04:57（K 棒起始時間），午夜後歸前一天開始的夜盤。

多空策略（`src/lib/strategy.ts`）：收盤站上 VAH 區上緣做多、跌破 VAL 區下緣做空；收盤回到區域另一側停損；停利為價值區高度 × 倍數；訊號看收完的 K 棒、下一根開盤成交；每盤最後三根平倉不留倉；穿越當下已超過停利價不追。

## 資料

| 資料 | 來源 | 說明 |
| --- | --- | --- |
| 台指期 3 分 K | 臺灣期貨交易所「前 30 個交易日期貨每筆成交資料」 | 逐筆合成，取當日成交量最大的月份合約；成交量為單邊（檔案的 B+S 除以 2） |
| 剛收盤那一盤 | Yahoo 奇摩股市 `WTX&` 1 分鐘資料 | 期交所檔案下午才公布，在那之前暫代，之後被官方檔案取代 |
| 個股日線 | Formosa Lens 發布的 `data/h/<代號>.json` | 同一個 GitHub Pages 帳號下的另一個網站 |

期交所只保留 30 個交易日，所以每個交易日的 K 棒會存成 `history/tx/<日期>.json` 並由 Actions 提交回倉庫，歷史靠這樣累積。**請勿手動修改 `history/`。**

抽查：2026-11-25 的日盤與夜盤開高低收與期交所行情表完全相同，成交量相差約 0.05%（行情表含價差單的成交）。

## 更新排程

`.github/workflows/deploy.yml`：每次推上 `main`、手動執行，以及平日台北時間 05:10、06:30、07:45（夜盤收盤後）、13:55、14:25（日盤收盤後）、17:15（官方檔案公布後）。GitHub 的排程常延後，所以每個時點排了不只一次。流程：測試 → `npm run data:build` → 提交 `history/` → 建置 → 發布到 GitHub Pages。不需要任何 secret。

## 本機開發

```bash
npm install
npm run data:build   # 需要連網與 unzip；產生 public/data/
npm run dev
npm test
npm run build
```

## 限制

- 不是即時；沒有休市日曆（「下一盤」按週一到週五推算）。
- 回測樣本小，成交價為理想化假設（下一根開盤價加固定成本）。
- 個股 AVWAP 的「VAH」在日線上只能得到收盤價所在價格格子的上緣，不是真正的每日成交量分布。

本工具僅供研究，不構成投資建議。
